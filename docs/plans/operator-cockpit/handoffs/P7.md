## Cold startup

Both runs alternated 20 cold loads per build on the same i7-1365U in Balanced mode with Node 22.12.0 and Edge 158.0.4370.33 in software mode. The runner used the P1 dense fixture `cockpit-public-v1`, a 1440 × 900 viewport, cold cache and blocked optional fonts. To reproduce, run `node tests/tools/cockpit-baseline.mjs '--baseline-dir=.hud-tmp/cockpit P1 base' --baseline-revision=797a9b944ed8ca3122a9681e31aec2c414be28bc --candidate-dir=. --loads=20 --output=.hud-tmp/cockpit-p7-baseline.json`.

| Run | P1 median / p95 | P7 median / p95 | Change |
|---|---:|---:|---:|
| First | 203.05 / 257.50 ms | 206.35 / 279.60 ms | +1.6% / +8.6% |
| Repeat after the test suites exited | 228.25 / 284.90 ms | 232.80 / 307.30 ms | +2.0% / +7.9% |

All loads passed the two hard gates with one SSE stream, zero cockpit, inspector or private requests and zero WebGL context calls. The initial SSE frame stayed at 19,124 B. Both builds received zero additional typed frames in the 30-second idle windows. Idle server CPU was 0% of one core for both builds on the repeat and 0.05% for P7 on the first run.

Local assets went from 42 requests and 267,189 B to 46 requests and 290,178 B. The added requests are the shared `discreet`, `entity-key`, `page-effects` and `route` modules. The proposed 5% p95 target was exceeded in both runs. Preserve both traces for P12’s packaged comparison and use them to investigate the shared startup path if the delta persists there.
