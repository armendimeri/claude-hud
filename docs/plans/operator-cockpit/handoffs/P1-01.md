## Decisions taken

- The visible word for a waiting session is NEEDS YOU, the existing HUD vocabulary, not "Waiting".
- The completion in the sparse composition is session "Check totals" shown as DONE (90 s), so counts are 3 sessions, 1 working, 1 needs you, 1 subagent. This is a composition of `snapshots.sparse`, not one of the frozen snapshots; the dense frames use `snapshots.dense` counts exactly (24, 7, 1, 1). If P2/P3 want a frozen "completed" sparse state, P1 can add it.
- Inspector widths 400 (side or overlay) and 480 (expanded, dense desktop only); side by side only when at least 640 px of map remains.
- Discreet display also hides provider letters and models, not only names and text.
- Narrow screens collapse projects to one hexagon with a count and keep the waiting session individual; the full node list is the accessible list.
